# Cyclotrone Calculator

Настольный калькулятор активности радиофармацевтических препаратов.

Приложение рассчитывает активности потребителей с учётом радиоактивного
распада, периода полураспада выбранного изотопа, радиохимического выхода,
параметров синтеза, фасовки и работы циклотрона.

## Технологии

- Rust
- Dioxus Desktop
- SQLite через `rusqlite`

## Сборка

Для проверки проекта:

```powershell
cargo check
cargo test
```

Для релизной сборки:

```powershell
cargo build --release
```

Готовый исполняемый файл появится в:

```text
target/release/dioxus_windows_form.exe
```

## Переносимое хранение данных

При запуске приложение создаёт каталог `data` рядом с исполняемым файлом:

```text
папка программы/
├── dioxus_windows_form.exe
└── data/
    └── calculator.sqlite3
```

Каталог `data` содержит пользовательские препараты, настройки и сохранённые
расчёты. Он исключён из Git и должен храниться вместе с установленной копией
программы.
